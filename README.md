🎉 Finance Tracker
Welcome to the Finance Tracker, a powerful and user-friendly application designed to help you manage your finances with ease. From tracking your income and expenses to visualizing your budget, this tool has everything you need to stay on top of your finances.

🚀 Features

📊 Dashboard Visualization

Gain insights into your financial health with interactive charts powered by Chart.js.
Visualize your income and expenses by category.

📝 Transaction Management

Add transactions based on specific categories.
View a summary of transactions in a clean and organized tabular format.
Export your transactions as PDF or CSV, filtered by date for convenience.

💰 Budgeting Tools

Create a personalized budget to track your spending.
Visualize your budget progress with intuitive graphs and metrics.

👤 User Authentication

Securely create an account, log in, and log out.

🛠️ Technology Stack

Frontend: HTML, CSS, Javascript, Bootstrap, Chart.js

Backend: Django, Python

Database: SQLite3

File Formats: PDF and CSV generation

Hosting: [Pythonanywhere]

📦 Installation

Prerequisites


Steps

1. Clone the repository:

git clone https://github.com/jaytech504/finance_tracker.git

cd finance_tracker

2. Install dependencies:

pip install -r requirements.txt

3. Set up the database:

Update your DATABASES configuration in settings.py.

4. Apply migrations:

python manage.py migrate

5. Run the server:

python manage.py runserver

Open the app in your browser at http://127.0.0.1:8000.

🔧 Usage
Register/Login: Create an account 

Add Transactions: Log your income or expenses under categories manually or by uploading csv file.

View Dashboard: Check your financial insights.

Generate Reports: Export transactions as PDF or CSV.

Set a Budget: Monitor and visualize your spending against your budget.

Uses Django’s built-in authentication system for secure user management.
